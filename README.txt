MODICUS ANALISTA — TESTE

1. Para um teste rápido:
   - Abra index.html num navegador moderno.
   - Os dados ficam guardados localmente no próprio navegador.

2. Para instalar no ecrã inicial como PWA:
   - É necessário servir esta pasta por HTTPS (por exemplo GitHub Pages, Netlify ou servidor próprio).
   - Depois abra no Chrome do tablet e escolha "Adicionar ao ecrã principal".

FUNÇÕES INCLUÍDAS:
- Cronómetro 2 x 30:00 corridos
- Plantel e 5 titulares
- Substituições com registo automático do minuto
- Remate nosso / adversário
- Golo nosso / sofrido
- Cronologia completa
- Minutos jogados por atleta
- Nº de entradas, golos e remates
- Dashboard do jogo
- Exportação JSON e CSV
- Gravação local automática

Nota: esta é uma versão de teste. O dashboard do campeonato será a fase seguinte, depois de validares o fluxo do jogo ao vivo.
